# TURTUBE

Turtube is a YouTube downloader API built with Bun.

> This is all powered by the [yt-dlp](https://github.com/yt-dlp/yt-dlp) project. Go check them out!

## Roadmap

- [x] Queued downloads
- [x] Multiple concurrent workers
